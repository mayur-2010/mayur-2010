## 🚀 Featured Projects

### 🍔 1. Food Delivery Analytics

**MySQL | Python | Power BI**

An end-to-end analytics project exploring food delivery operations, customer behavior, restaurant performance, and revenue.

**Project Outcomes:**
- Analyzed 15,000 orders across 6 cities.
- Worked with 4,500 customers and 90 restaurants.
- Calculated revenue, average order value, and cancellation rate.
- Developed an interactive dashboard with 7 KPI measures.
- Identified an 8.85% order cancellation rate in the synthetic dataset.

### 💳 2. UPI Fraud & Customer Behavior Analytics

**Python | Machine Learning | Power BI**

Analyzed UPI transaction patterns and applied machine learning algorithms to identify potential fraudulent transactions.

**Project Outcomes:**
- Compared multiple classification algorithms.
- Achieved 72.11% accuracy using AdaBoost.
- Achieved 73.84% ROC-AUC with AdaBoost.
- Evaluated model performance using classification metrics.

### 🛕 3. Temple Crowd Pressure Index Prediction

**Python | Pandas | Scikit-learn | Machine Learning**

Developed a machine learning project to estimate crowd pressure and identify potential risk levels in temple gatherings.

**Project Outcomes:**
- Analyzed approximately 12,009 records.
- Worked with 15 original dataset columns.
- Engineered crowd density, inflow, outflow, and capacity-related features.
- Designed a Crowd Pressure Index from 0–100.
- Defined Safe, Moderate, and Critical risk categories.
